# 搜索质量自检清单

用于快速检查搜索结果质量，建议在输出前对照检查。

---

## 一、搜索前检查

### 问题理解
- [ ] 我是否理解了用户的真实问题？
- [ ] 问题的核心是什么？
- [ ] 是否需要最新信息？

### 搜索策略
- [ ] 搜索关键词是否准确？
- [ ] 是否需要使用特定搜索语法（site:、filetype: 等）？
- [ ] 是否需要多个搜索词？

---

## 二、搜索过程检查

### 来源质量
- [ ] 是否找到了官方或权威来源？
- [ ] 来源是否足够可信？
- [ ] 是否有多个独立来源？

### 时效性
- [ ] 来源的发布时间是什么？
- [ ] 信息是否可能已过时？
- [ ] 是否需要寻找更新的来源？

### 完整性
- [ ] 是否回答了用户的所有问题？
- [ ] 是否有遗漏的关键信息？
- [ ] 是否需要进一步搜索？

---

## 三、输出前检查

### 事实准确性
- [ ] 核心结论是否有来源支撑？
- [ ] 是否混淆了事实和推断？
- [ ] 是否有过度概括？

### 来源引用
- [ ] 是否为每个关键事实提供了引用？
- [ ] 引用格式是否规范？
- [ ] 链接是否有效？

### 不确定性披露
- [ ] 是否存在不确定的部分？
- [ ] 是否已明确说明不确定点？
- [ ] 是否有来源冲突需要说明？

### 输出格式
- [ ] 输出结构是否清晰？
- [ ] 语言是否简洁明了？
- [ ] 是否易于理解？

---

## 四、风险等级检查

### 低风险任务（普通事实）
- [ ] 至少 1 个高可信来源
- [ ] 来源类型为官方、权威或主流媒体
- [ ] 信息稳定，不易变化

### 中风险任务（重要结论）
- [ ] 至少 2 个独立来源
- [ ] 其中 1 个为官方或原始来源
- [ ] 已检查来源时效性
- [ ] 已说明不确定点（如有）

### 高风险任务（决策依据）
- [ ] 至少 2-3 个来源
- [ ] 必须包含原始来源（官方公告、法规原文、论文原文等）
- [ ] 已处理来源冲突
- [ ] 已明确披露不确定性和风险

---

## 五、常见问题检查

### 信息准确性
- [ ] ❌ 是否把旧闻当新闻？
- [ ] ❌ 是否把推断当事实？
- [ ] ❌ 是否过度依赖单一来源？
- [ ] ❌ 是否使用了不可靠的来源（仅社交平台）？

### 引用规范
- [ ] ❌ 是否遗漏了关键引用？
- [ ] ❌ 是否伪造了引用？
- [ ] ❌ 是否引用了不可访问的链接？

### 输出质量
- [ ] ❌ 输出是否过于冗长？
- [ ] ❌ 是否回答了无关问题？
- [ ] ❌ 是否使用了模糊语言？

---

## 六、快速检查表（简化版）

**必查项**（每次都检查）：
- [ ] 核心结论有来源支撑
- [ ] 事实和推断分开
- [ ] 不确定点已说明

**建议项**（重要任务检查）：
- [ ] 多个独立来源
- [ ] 官方或原始来源
- [ ] 时效性已确认

---

## 七、质量评分

完成检查后，可对搜索结果进行评分：

| 维度 | 评分（1-5） | 说明 |
|------|-------------|------|
| 准确性 | | 结论是否准确 |
| 完整性 | | 是否回答了所有问题 |
| 可信度 | | 来源是否可靠 |
| 时效性 | | 信息是否最新 |
| 清晰度 | | 输出是否清晰 |

**总评分**：____ / 25

- **≥ 20**：优秀，可直接交付
- **15-19**：良好，建议微调
- **10-14**：一般，建议补充
- **< 10**：不合格，需重新搜索
