# 搜索输出格式模板

## 标准输出结构

### 1. 结论摘要

一句话回答核心问题，直接给出答案。

```markdown
**结论**：[一句话回答]
```

### 2. 关键依据与来源

列出支撑结论的证据，每个事实后跟引用。

```markdown
**依据**：
1. [事实 1] — 来源：[来源名称]（[来源类型]）[链接]
2. [事实 2] — 来源：[来源名称]（[来源类型]）[链接]
3. [事实 3] — 来源：[来源名称]（[来源类型]）[链接]
```

### 3. 逻辑说明（可选）

简要说明推理过程。

```markdown
**推理**：[简要说明如何从依据得出结论]
```

### 4. 不确定点与边界

明确说明不确定的部分。

```markdown
**不确定点**：
- [不确定内容 1] — 原因：[为什么不确定]
- [不确定内容 2] — 原因：[为什么不确定]
```

若无不确定点，可省略此部分。

### 5. 可执行建议（可选）

下一步行动建议。

```markdown
**建议**：[下一步可以做什么]
```

## 完整示例

### 示例 1：快速事实查证

```markdown
## 结论摘要

**结论**：OpenAI 的现任 CEO 是 Sam Altman。

## 关键依据与来源

1. OpenAI 官网领导团队页面显示 Sam Altman 为 CEO — 来源：OpenAI 官网（官方）https://openai.com/leadership
2. 2024 年 11 月新闻报道确认 Sam Altman 回归 CEO 职位 — 来源：TechCrunch（主流媒体）https://techcrunch.com/2024/11/...

## 不确定点与边界

无重大不确定点。信息来源于官方页面和主流媒体报道，时效性良好。
```

### 示例 2：当前动态查询

```markdown
## 结论摘要

**结论**：GPT-4 Turbo 的最新版本是 GPT-4-turbo-2024-04-09，支持 128K 上下文窗口。

## 关键依据与来源

1. OpenAI 官方模型文档确认 GPT-4-turbo-2024-04-09 为最新稳定版本 — 来源：OpenAI Docs（官方）https://platform.openai.com/docs/models
2. 发布说明显示该版本于 2024 年 4 月发布 — 来源：OpenAI Release Notes（官方）https://help.openai.com/...

## 不确定点与边界

- **模型更新频率**：OpenAI 可能随时发布新版本，建议定期检查官方文档

## 建议

访问 OpenAI 官方文档页面确认最新版本信息。
```

### 示例 3：存在不确定性的情况

```markdown
## 结论摘要

**结论**：根据目前可获取的信息，[公司名] 2024 年营收约为 [数值]，但存在较大不确定性。

## 关键依据与来源

1. 财经媒体报道营收为 [数值 A] — 来源：[媒体名称]（主流媒体）[链接]
2. 行业分析报告提到营收为 [数值 B] — 来源：[分析机构]（权威机构）[链接]

## 不确定点与边界

- **数据不一致**：不同来源给出的营收数字存在差异（[数值 A] vs [数值 B]）
- **官方财报缺失**：未能找到公司官方财报或公告
- **时效性**：部分数据可能已过时

## 建议

查阅公司官方财报或投资者关系页面获取权威数据。
```

## 引用格式规范

### 标准引用格式

```markdown
[事实内容] — 来源：[来源名称]（[来源类型]）[链接]
```

### 来源类型标注

- **官方**：官方网站、官方公告、官方文档
- **权威**：研究机构、监管机构、专业出版社
- **媒体**：主流新闻媒体、专业媒体
- **二手**：博客、转引、摘要
- **社交**：Twitter、Reddit、论坛（需特别标注）

### 示例

```markdown
OpenAI 于 2024 年发布 GPT-4o — 来源：OpenAI Blog（官方）https://openai.com/blog/gpt-4o
```

## 不确定性披露格式

### 标准格式

```markdown
⚠️ 不确定性说明：

**不确定点**：[具体内容]
**原因**：[为什么不确定]
**影响范围**：[对结论的影响]
**建议**：[如何进一步核验]
```

### 来源冲突格式

```markdown
⚠️ 来源冲突：

**冲突点**：[具体事实]

**来源 A**：[说法]（[来源类型]，[发布时间]）
**来源 B**：[说法]（[来源类型]，[发布时间]）

**判断**：[可信度分析]
**结论**：目前无法确定 / 倾向于 [来源]
```
